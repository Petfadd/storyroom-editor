# The headless build is required, not preferred: the app never opens a window, and the
# GUI build needs a display library that a server, or a session without one, does not
# provide. scenedetect (below) declares a dependency on the *GUI* `opencv-python`, so pip
# installs it alongside this one; both then own the same `cv2` package, the GUI one wins,
# and `import cv2` fails with a missing libGL.so.1 -- which stops the editor from starting
# at all, not just from detecting scenes. `requirements-constraints.txt` is what prevents
# that, and it is passed automatically by the commands in the README.

# CPU, memory, disk and load readings, and therefore every decision about how many
# heavy jobs may run, when to hold back, and whether a large operation fits. Without it
# the app still runs, but the queue cannot see the machine it is managing, so the
# performance controls degrade to doing nothing. That is not an acceptable default for
# a feature whose whole point is resource management.
